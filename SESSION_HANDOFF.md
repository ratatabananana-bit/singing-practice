Tests `sections.test.ts`, `dedupe.test.ts`.
   - **Tap rules** in `src/state/loopTaps.ts` `tapAction(startIdx, endIdx, count, loop, pendingStart)`: tap → loop that one segment and remember the start as pending; a later tap right after → that is the end; any later tap → new start. Pending is only honoured while the loop still is that one segment, so anything else forgets it. Double-tap → jump, loop restored (unchanged). Marker pins: start = end = i.
